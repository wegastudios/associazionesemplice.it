= Updates from the associazionesemplice.it website (only in the copy downloaded from associazionesemplice.it) =
This copy of the plugin was downloaded from https://associazionesemplice.it, not from WordPress.org. To offer updates in Dashboard - Updates, it asks that website for the latest version: it sends a request to https://associazionesemplice.it/api/plugin/update, at most every 12 hours or more (24 hours by default; Settings - Limits and thresholds lets you choose from 12 to 168 hours), even without a license key, and never from local development sites (localhost, IP addresses, .local, .test and similar). The request contains only the product name ("free") and the installed plugin version. It does not contain a license key, a domain name or any member or association data. As with any web request, the website receives the IP address of your server and the standard WordPress User-Agent, which includes your site address. When you press Update, the plugin asks the website again for the update package, which is signed and checked before it is installed. You can turn this off in Settings - Limits and thresholds (the option "Direct updates of Associazione Semplice and of Pro"): nothing is then sent, and updates must be downloaded from the customer area and uploaded by hand. If the Associazione Semplice Pro add-on is active, the request also carries its license key and your domain name, as described in the readme of that add-on. This website is run by the plugin's authors. The copy of the plugin distributed on WordPress.org does not contain this feature, never contacts that website and is updated by WordPress.org.
